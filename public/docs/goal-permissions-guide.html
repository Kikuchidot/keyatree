目標設定 権限・承認・一時差戻
運用手順書

定量・定性目標設定シートにおける管理者権限の設定方法、承認者割り当て、提出から承認までのフロー、および承認済みシートへの一時差戻（編集許可）の運用手順をまとめた資料です。

対象システムk-ai-app.vercel.app
対象読者管理者 / 人事管理者 / 承認者 / 全スタッフ
バージョンv1.0
公開日2026年10月

この資料について

目標設定機能の権限は「管理者」「担当承認者（一次・二次）」「設定者（本人）」の3層で構成されます。基本的に、設定者の提出物は割り当てられた承認者と管理者のみが閲覧・編集でき、承認済みシートは編集ロックされますが、管理者による一時差戻（編集許可）を発行すると設定者・承認者が全項目を編集できるようになり、編集箇所は赤字で記録されます。

1

権限の種類と設定方法

権限の一覧

権限目標設定シートの扱い
システム管理者全スタッフの定量・定性の提出物を閲覧・編集・承認・差戻し可能。一時差戻の発行/解除が可能。
人事管理者システム管理者と同等の操作が可能。
担当承認者割り当てられた設定者の提出物のみ閲覧・編集・承認・差戻し可能。
設定者（本人）自分の提出物の閲覧・編集が可能。
その他他人の提出物の閲覧・編集は不可。

管理者権限の設定手順

  1. 機能一覧を開くログイン後、/features の「管理・運用」にある「アカウント管理」カードを開きます（管理者権限のアカウントのみ表示）。
  2. アカウントを選択権限を変更したいアカウントの「編集」を押します。
  3. 権限を設定「システム管理者」または「人事管理者」を選択して保存します。

アカウント管理ページの直URL: /settings/accounts

2

承認者割り当て

割り当て画面

対象期間（例: 2026年10月）ごとに、設定者一人ひとりへ一次承認者・二次承認者を割り当てます。割り当ては定量・定性の両シートに共通適用されます。

割り当て画面: /approvals/goal-assignments（機能一覧「管理・運用」→「承認者割り当て」カード）

  • 一次承認者は必須。二次承認者は四半期の評価タイミングなどで後から追加可能
  • 設定者本人・一次承認者と同じ人物は二次承認者に指定不可
  • 対象/対象外の切替と並び順（ドラッグ＆ドロップ）は全期間・全シート共通で保存
  • 対象外にした設定者は自動でリスト末尾へ移動

各状況の見え方

項目表示内容
設定者名前の下に提出状況バッジ（未対応 / 下書き / 提出済み / 承認済み / 差戻）＋ 確定・差戻ボタン
一次承認者顔写真アイコン＋名前＋承認状況（未対応 / 提出待ち / 承認待ち / 承認済み / 差戻済み）
二次承認者一次承認済みのシートが「承認待ち」に切り替わる
3

提出から承認までのフロー

  1. 設定者がシートを提出定量・定性目標設定シートを記入し「提出」します。
  2. 承認者へ通知担当承認者（一次・二次）のマイページ上部に「承認依頼が届いています」パネルが表示されます。
  3. シートを確認通知の「シートを確認する」ボタンで確認・承認ページへ直接移動します。提出時と同一のシート形式で入力内容を確認できます。
  4. 承認 or 差戻問題なければ「確定」で承認。修正が必要なら「差戻」を選び、理由を入力して設定者へ差し戻します。
  5. 進捗の記入承認後は設定者・承認者がマイページや承認一覧から進捗数値・結果数値を直接入力できます。
閲覧範囲:承認一覧（/approvals/goal-navigators）には、管理者は全件、担当承認者は自分の担当分のみ表示されます。担当割り当てがまだ無いアカウントでも、割り当てられれば自動的に承認一覧を利用できるようになります。
4

一時差戻（編集許可）機能

できること

設定者からの希望などに応じて、管理者が承認済みシートを一時的に編集可能な状態にできます。一時差戻中は次のルールが適用されます。

  • 設定者・承認者のどちらも全項目を編集・保存できる
  • 編集された項目は赤枠＋赤字で表示され、すぐ下に編集者: ○○（日時）が記録される
  • 元の値に戻すと赤字表示は自動で消える
  • 一時差戻していない承認済みシートは、進捗数値・結果数値のみ編集可能

操作手順（管理者）

  1. 対象シートを開く承認一覧または承認済み一覧から、対象の承認済みシート詳細を開きます。
  2. 一時差戻を発行シート上部の「一時差戻（編集許可）」ボタンを押し、理由（任意）を入力して発行します。
  3. 編集を実施設定者・承認者がシートを編集・保存します。編集箇所は赤字で記録されます。
  4. 編集を終了「編集を終了してロック」ボタンで再ロックすると、以降は進捗数値・結果数値のみ編集可能に戻ります。

操作対象ページ: /approvals/goal-navigators/[ID]（シート詳細）

注意:一時差戻の発行/解除は管理者（システム管理者・人事管理者）のみ可能です。設定者のマイページ（過去の目標履歴）にも「一時差戻中」の案内が表示され、同じく赤字編集ができます。
